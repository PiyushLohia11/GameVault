# Game Backlog + Achievement Database — Frontend

Frontend application for the **Game Backlog & Achievement Database** college DBMS project.

## Tech Stack
- **Framework:** React + JavaScript (Vite)
- **Routing:** React Router v6
- **Styling:** Vanilla CSS with centralized design tokens (`src/styles/tokens.css`)
- **Theme:** Black (#040404) & Gold (#F4BF4E) gaming aesthetic with subtle grid overlay
- **Icons:** Lucide React

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port indicated in your terminal).

### 3. Build for Production
```bash
npm run build
```

### 4. Preview the Production Build
```bash
npm run preview
```

## Project Routes
- `/` — Dashboard Overview (`01-dashboard.md`)
- `/library` — My Library (`02-my-library.md`)
- `/discover` — Discover Catalogue (`03-discover-catalogue.md`)
- `/games/:id` — Game Details (`04-game-details.md`)
- `/achievements` — Achievements & Milestones (`05-achievements.md`)
- `/friends` — Friends & Social Comparison (`06-friends.md`)
- `/reviews` — Game Reviews (`07-reviews.md`)
- `/settings` — Settings & Preferences (`08-settings.md`)
- `*` — 404 Fallback
